# بک‌فایر 🔥

**بک‌فایر** یک تونل معکوس (Reverse Tunnel) پرسرعت است که کاملاً با **Go** نوشته
شده و برای ست‌آپ سرور ایران ⇄ خارج طراحی شده. یک **باینری واحد** با یک منوی
تعاملی است — تونل‌هایت را بدون ویرایش دستی فایل کانفیگ یا نوشتن یونیت systemd
می‌سازی و مدیریت می‌کنی.

> 📖 English guide: **[README.md](README.md)**

---

## معماری

کاربر به یک **پورت منتشرشده** روی سرور نمایان (VPS ایران) وصل می‌شود؛ انجین آن را
از طریق **یک لینک ترنسپورت مالتی‌پلکس‌شده** به کلاینت خارج می‌برد و کلاینت آن را
به **سرویس واقعی** می‌رساند.

```
   کاربر ──▶ :443 (سرور نمایان) ══ ترنسپورت+ماکس ══▶ کلاینت خارج ──▶ 127.0.0.1:443
                [ نقش سرور ]                            [ نقش کلاینت ]
```

خودِ تونل همیشه **توسط کلاینت** برقرار می‌شود (خارج → ایران)، پس سمت خارج نیازی
به پورت ورودی باز ندارد. هر اتصالِ forward‌شده به‌صورت یک استریمِ مستقل و
کنترل‌جریان‌دار روی یک اتصال فیزیکی واحد جابه‌جا می‌شود.

---

## چرا بک‌فایر؟

- **چند-ترنسپورت:** `tcp` برای سرعت خام، `ws` برای عبور از CDN و پروکسی‌های
  لایه ۷، و `wss` برای همان به‌علاوه‌ی TLS. یک تونل، فقط با عوض‌کردن یک کلمه.
- **مالتی‌پلکس استریم:** همه‌ی اتصال‌ها روی یک لینک با
  [smux](https://github.com/xtaci/smux) و کنترل‌جریانِ هر استریم — بدون طوفانِ
  اتصال و بدون هزینه‌ی هندشیک به‌ازای هر اتصال.
- **هندشیک احرازهویت‌شده و مقاوم در برابر replay:** دو طرف با یک توکن مشترک و
  چالش/پاسخ HMAC-SHA256 همدیگر را تایید می‌کنند؛ توکن حتی روی لینک `tcp` ساده هم
  از روی سیم عبور نمی‌کند.
- **کلاینتِ خودترمیم:** لینکِ قطع‌شده با backoff نمایی و jitter کامل دوباره برقرار
  می‌شود، پس تونل بعد از هر قطعی خودش برمی‌گردد.
- **بهره‌برداری بدون دردسر:** منو کانفیگ را می‌نویسد، یونیت systemd (با
  `Restart=always`) را می‌سازد، فعال و اجرا می‌کند. به‌صورت پیش‌فرض مقاوم در برابر
  ریبوت.
- **کوچک و قابل‌بازبینی:** چند پکیجِ متمرکز، بدون درختِ وابستگیِ بزرگ.

## شروع سریع

روی VPS، به‌عنوان root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/thenawid/backfire/main/install.sh)
```

نصب‌کننده باینری را می‌سازد، در `/usr/local/bin/backfire` نصب می‌کند و منو را باز
می‌کند. هر وقت خواستی دوباره باز کن:

```bash
sudo backfire
```

### ۱. روی سرور نمایان (ایران)

`backfire` → **Create server tunnel**. یک پورت listen، یک ترنسپورت و forwardهایت
را وارد کن (مثلاً `443=127.0.0.1:443`). یک **توکن** چاپ می‌شود — کپی‌اش کن.

### ۲. روی سرور مبدأ (خارج)

`backfire` → **Create client tunnel**. آدرس سرور، همان ترنسپورت و توکن را وارد
کن. تمام — کلاینت وصل می‌شود و تونل بالا می‌آید. هر دو طرف بعد از ریبوت خودشان
برمی‌گردند.

## پیکربندی دستی

هر تونل یک فایل TOML در `/etc/backfire/` است که با یک یونیت systemd اجرا می‌شود.
می‌توانی دستی هم بنویسی — به [`examples/server.toml`](examples/server.toml) و
[`examples/client.toml`](examples/client.toml) نگاه کن.

```bash
backfire -c /etc/backfire/main.toml      # حالت engine (چیزی که systemd اجرا می‌کند)
backfire                                 # منوی تعاملی
backfire -v                              # نسخه
```

### فرمت forward

هر ورودی به شکل `<listen>=<target>` است:

| ورودی | منتشر روی سرور | کلاینت وصل می‌شود به |
|---|---|---|
| `443=127.0.0.1:443` | `0.0.0.0:443` | `127.0.0.1:443` |
| `0.0.0.0:2222=127.0.0.1:22` | `0.0.0.0:2222` | `127.0.0.1:22` |
| `8080` | `0.0.0.0:8080` | `127.0.0.1:8080` |

## ترنسپورت‌ها

| ترنسپورت | رمزنگاری | شبیهِ | کِی؟ |
|---|---|---|---|
| `tcp` | ندارد | هیچ | مسیر تمیز است و کمترین سربار را می‌خواهی |
| `ws`  | ندارد | HTTP/WebSocket | یک CDN یا پروکسی لایه۷ جلوی مسیر است |
| `wss` | دارد (TLS) | HTTPS/WebSocket | هم رمزنگاری می‌خواهی هم سازگاری با CDN |

برای `wss`، خالی‌گذاشتنِ `tls_cert`/`tls_key` یک گواهی self-signed در حافظه می‌سازد
— و این اشکالی ندارد، چون دو طرف با **توکن** همدیگر را تایید می‌کنند، نه با زنجیره‌ی
گواهی. اگر دامنه‌ی مشخصی را terminate می‌کنی، به یک گواهی واقعی اشاره بده.

## نکات امنیتی

- توکن کلِ مرزِ امنیت است — یک مقدار تصادفیِ بلند بساز (گزینه‌ی ۷ منو) و فایل‌های
  کانفیگ را `0600` نگه‌دار (نصب‌کننده این کار را برایت انجام می‌دهد).
- روی کلاینت می‌توانی `allowed_targets` را ست کنی تا دقیقاً مشخص شود سرور اجازه‌ی
  درخواست dial به کدام `host:port` را دارد.
- فایل‌های کانفیگ توکن واقعی دارند — هیچ‌وقت در گیت قرارشان نده (الگوهای
  `.gitignore` هم آن‌ها را نادیده می‌گیرند).

## ساخت و تست از سورس

```bash
git clone https://github.com/thenawid/backfire.git
cd backfire
make build      # -> ./backfire
make test       # تست‌های واحد + تونلِ سرتاسریِ درون‌فرایندی روی tcp/ws/wss
make vet
```

تستِ سرتاسری در [`internal/e2e`](internal/e2e) یک سرور+کلاینتِ واقعی را روی
loopback برای هر ترنسپورت بالا می‌آورد و رفت‌وبرگشتِ بایت را از کلِ استک (هندشیک،
ماکس، فریمینگ، forwarding) بررسی می‌کند.

## نقشه‌ی راه

- ترنسپورت‌های بیشتر (KCP/QUIC برای مسیرهای پرافت)، forwarding روی UDP

- متریکِ هر تونل و واچ‌داگ سلامت
- باینری‌های آماده‌ی release با نصبِ تاییدشده با checksum
